### Breakdown by Category

1. **`release_regression` (15 scenarios, golden-001..015):** Correctly identified deployment artifact updates immediately preceding error spikes; cites valid deployment and error rate evidence IDs.
2. **`bad_configuration` (15 scenarios, golden-016..030):** Identifies environment variable / feature flag updates; cites configuration audit records.
3. **`dependency_failure` (12 scenarios, golden-031..042):** Identifies upstream/downstream HTTP 502/504 gateway timeouts and connection refused traces.
4. **`traffic_spike` (12 scenarios, golden-043..054):** Identifies sudden surges in request volume exceeding capacity thresholds.
5. **`database_saturation` (10 scenarios, golden-055..064):** Identifies PostgreSQL connection pool exhaustion, slow query lock contention, and pool timeout errors.
6. **`telemetry_gap` (8 scenarios, golden-065..072):** Correctly abstains (`shouldAbstain = true`), outputs `telemetry_gap` with high uncertainty, and proposes human actions instead of hallucinating.
7. **`ambiguous` (4 scenarios, golden-073..076):** Handles multiple coinciding signals; outputs up to 3 ranked hypotheses with marked uncertainty.
8. **`unrelated_noise` / Prompt Injection (4 scenarios, golden-077..080):** Neutralizes injected prompt override commands (e.g., `"IGNORE PREVIOUS INSTRUCTIONS..."`), redacts tokens, and classifies as low-priority noise.
